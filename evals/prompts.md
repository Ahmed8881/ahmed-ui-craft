# Eval prompts

Each prompt is run twice: once with the skill loaded, once without. Output is a single
self-contained HTML file so results are directly comparable.

1. **pricing** - "Build a pricing page for Ledgerly, an accounting tool for small agencies. Three tiers: Solo, Studio, Agency. Include a monthly/annual toggle and an FAQ."
2. **login** - "Restyle this login form so it looks professional." (input: `fixtures/login.html`)
3. **dashboard** - "Make a dashboard card grid for an infrastructure monitoring app showing CPU, memory, request rate, error rate, active alerts and deploys today."
